# 总结

Dart 在开发时用 JIT，才能热重载；发布到手机和桌面时用 AOT，编成原生机器码。界面和业务共用这一门带类型的语言。选它，不是因为它比别的语言更漂亮。

<!-- section: 专业讲解 -->
## 两头编译

- 开发时走 JIT，改完就能热重载
- 手机和桌面发布时走 AOT，得到原生机器码
- 类型把界面参数和业务数据放在同一门语言里检查
- 理由是这两头，不是文采

<!-- section: 大白话 -->
## 大白话

- 同一支笔。草稿可以涂改，定稿可以付印

<!-- section: 怎么用 -->
## 怎么用

```dart
String greet(String name) {
  return 'Hello $name';
}
```

- 这种函数，界面和业务都能调用
- 开发时靠热重载，发布时再做 AOT

<!-- section: 再讲深一点 -->
## 再讲深一点

- 网页的编译和手机不同，框架还是这一份
- 参数对不上时，编译器会先拦住
- 界面也是 Dart，不必再找一门标记语言

<!-- section: 边界 -->
## 边界

- 它不替你把接口设计变好
- 语言再合适，也挡不住难懂的写法

<!-- section: 收束 -->
## 留下这句

- 要的是 JIT、AOT，以及同一门带类型的语言
