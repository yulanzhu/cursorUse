# 总结

参数分位置参数、命名参数，也有可以省略的可选参数。命名参数让调用的地方读得懂。闭包抓住外层变量，不是抓住一份拷贝。箭头函数是表达式函数的短写。

<!-- section: 专业讲解 -->
## 参数和函数体

- 位置参数按顺序传入
- 命名参数在调用时写上名字，次序可以调整
- 方括号里的位置参数可以省略
- 花括号里的命名参数默认可以省略，写了 `required` 就必须传入
- 闭包抓住的是外层那个变量
- `=>` 后面只能放一个表达式，表达式的值就是返回值

<!-- section: 大白话 -->
## 大白话

- 点菜时把菜名说出来，就不用靠第几个去猜
- 闭包拿走的是灶台上的那个变量，不是抄下来的副本

<!-- section: 怎么用 -->
## 怎么用

```dart
void greet({required String name, int times = 1}) {
  print('$name $times');
}

int twice(int value) => value * 2;

int apply(int step) {
  int add(int value) => value + step;
  return add(10);
}
```

- `name` 必须写上，`times` 可以不写
- `twice` 是箭头函数
- `add` 抓住了外层的 `step`

<!-- section: 再讲深一点 -->
## 再讲深一点

- 外层变量后来改了，闭包再执行，看到的是新值
- 可选参数的默认值必须是编译期常量

<!-- section: 边界 -->
## 边界

- 箭头函数写不了多条语句。要多条，就用花括号
- 必填的命名参数用关键字 `required`，不是老代码里的注解

<!-- section: 收束 -->
## 留下这句

- 想让调用的地方读得懂，就用命名参数。闭包抓住变量，箭头函数只写一个表达式
