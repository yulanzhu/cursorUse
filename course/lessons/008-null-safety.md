# 总结

类型默认不能是空值。`?` 表示可以是空值。`??` 在左边是空值时给替代值。`!` 是你向编译器打包票，打错就在运行时撞上。`late` 也会给空安全让路。

<!-- section: 专业讲解 -->
## 空值怎么过

- 没有问号的类型，不能是空值
- `?` 表示这个类型可以是空值
- `??` 只在左边是空值时，改用右边
- `!` 是你向编译器打包票，打错就在运行时撞上
- `late` 允许一个不能是空值的变量晚一点赋值

<!-- section: 大白话 -->
## 大白话

- 空值像没写地址的信封。问号表示允许，两个问号表示改寄，叹号是你拍胸脯

<!-- section: 怎么用 -->
## 怎么用

```dart
String shown(String? name) {
  return name ?? 'guest';
}
```

- 左边是空值时，结果才是 `'guest'`
- 空字符串不会被换掉

<!-- section: 再讲深一点 -->
## 再讲深一点

- `if (name != null)` 之后，类型会收窄，不必再写 `!`
- `?.` 在左边是空值时直接得到空值，不会继续调用

<!-- section: 边界 -->
## 边界

- 不要习惯性写 `!`。票打错了，要到运行时才爆
- `late` 读早了会抛 `LateInitializationError`，那是程序错误

<!-- section: 收束 -->
## 留下这句

- 默认不是空值。问号表示允许，两个问号给退路，叹号是你自己担保
