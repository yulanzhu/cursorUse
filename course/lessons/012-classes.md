# 总结

构造有默认构造、命名构造、初始化列表、重定向构造、工厂构造和 `const` 构造。初始化列表在构造函数体执行之前，给 `final` 字段赋值。

<!-- section: 专业讲解 -->
## 几种构造

- 你一旦写了任何构造，自动的无参构造就没有了
- 命名构造把名字写在类名后面
- 初始化列表用冒号，先于函数体，给 `final` 字段赋值
- 重定向构造自己没有函数体，只转到另一个构造
- 工厂构造可以返回已有实例，也可以返回子类
- `const` 构造的字段必须是 `final`，而且不能写函数体

<!-- section: 大白话 -->
## 大白话

- 正门、侧门，都能进楼。有的门只是把你领到另一扇门，前台也可以递一把已经有的钥匙

<!-- section: 怎么用 -->
## 怎么用

```dart
class Point {
  final int x;
  final int y;

  const Point(this.x, this.y);

  const Point.origin() : this(0, 0);

  Point.square(int side) : x = side, y = side;

  factory Point.cached() => const Point.origin();
}
```

- `Point.square` 在初始化列表里给 `x` 和 `y` 赋值
- `Point.origin` 把创建转给 `Point`，这就是重定向构造
- `Point.cached` 是工厂，返回已有的 `const` 实例

<!-- section: 再讲深一点 -->
## 再讲深一点

- 写成 `this.x` 的参数，也是在初始化列表里完成赋值
- 顺序是初始化列表，然后父类构造，然后才是函数体
- 重定向和初始化列表，不能写在同一个构造上

<!-- section: 边界 -->
## 边界

- 初始化列表里不能调用实例方法，对象这时还没准备好
- 命名构造不会被子类继承

<!-- section: 收束 -->
## 留下这句

- `final` 字段要在函数体执行之前赋好。差别在于，对象由谁交出来
