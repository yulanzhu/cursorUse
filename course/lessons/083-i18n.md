# 总结

`arb` 文件放各语言的句子，`gen-l10n` 生成取文案的代码。数量不同时句子可能要换一种说法，这条规则和占位符都交给文案。不要在代码里用加号拼出一句英文。

<!-- section: 专业讲解 -->
## 句子归文案

- 占位符把名字和数字留在完整句子里
- 数量不同时怎么选句子，写在文案里，因为不同语言的分法不一样
- 页面通过生成的类取句子，把参数传入
- 缺了那种语言的条目，界面就没有那句

<!-- section: 大白话 -->
## 大白话

- 代码交出数字和名字。句子由会写那种语言的人来写

<!-- section: 怎么用 -->
## 怎么用

```json
{
  "itemCount": "{count, plural, =0{没有条目} =1{1 条} other{{count} 条}}",
  "@itemCount": {
    "placeholders": { "count": { "type": "int" } }
  }
}
```

- 打开生成，让工具读 `arb` 并写出访问代码
- 不要用加号把英文单词接成用户能看见的句子

<!-- section: 再讲深一点 -->
## 再讲深一点

- 中文在数量变化时常常不改句子，英文要改，有的语言类别更多
- 日期和数字的写法也随语言变，能交给格式工具就不要手拼

<!-- section: 边界 -->
## 边界

- 生成不会替你发明翻译
- 运行时再去拼英文句子，翻译的人就改不动语序

<!-- section: 收束 -->
## 留下这句

- 句子、占位符，还有数量不同时的选句，都在文案里。代码只传入参数
