# Flutter 全量语音教程

在浏览器里按章节收听的 Flutter 课程。每课有口播、逐句文稿，以及配合机制的图示或动画。

语音是微软中文神经语音「晓晓」（`zh-CN-XiaoxiaoNeural`），语速略慢。这里没有录音棚真人配音。

## 听课

构建完成后，在仓库根目录执行：

```bash
npm start
```

浏览器打开 `http://127.0.0.1:4173`。空格键播放或暂停，左右方向键切换句子。进度记在本机浏览器里。

## 重新生成

课文在 `content/`。改完后执行：

```bash
npm run check
npm run build
```

`check` 只检查课文是否完整。`build` 会为新句子合成 mp3，并写出 `dist/`。某一句合成失败时，日志里会有课名和句子，构建不会悄悄跳过。
